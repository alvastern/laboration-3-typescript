# Laboration 3 - Typescript
I denna laboration har jag som student fått prova på att använda ramverket Angular för första gången. Resultatet är en webbplats med där användare kan konventera olika värden från centimeter och celcius, till fot och farenheit. Jag har genom Angular använt en automatiserad arbetsprocess och versionshanterat med Git och Github.
